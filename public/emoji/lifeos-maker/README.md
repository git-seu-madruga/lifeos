# LifeOS — Impressão 3D

17 ilustrações próprias do projeto, geradas com OpenAI a partir da prévia aprovada pelo usuário: nove ferramentas/objetos e oito rolos de filamento (laranja, branco, preto, vermelho, azul, verde, roxo e multicolorido).

Estilo tridimensional colorido, fundo transparente, WebP 128 × 128. Os arquivos são estáticos e locais; o app não gera imagens nem consulta serviços externos para exibi-los. A exportação preserva a transparência e reduz os arquivos para uso no seletor.

Este conjunto é independente do Microsoft Fluent Emoji; não é uma extensão oficial nem redistribuição de seus arquivos. As atribuições e a licença dos emojis anteriores permanecem em `../fluent-expanded/`. `sources.json` registra descrição, origem, tamanho e SHA-256 de cada arquivo. O barquinho é uma ilustração de teste de impressão, sem arquivo 3D ou logotipo de terceiros incluído.
