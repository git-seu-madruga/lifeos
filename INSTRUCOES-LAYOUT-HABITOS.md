# Layout dos hábitos encerrados

O status Encerrado e os botões de editar/recuperar agora ficam em uma área abaixo do nome do hábito. Cada palavra permanece na horizontal; em espaços estreitos, os controles ocupam linhas separadas sem alargar as colunas do calendário.

Atualize os arquivos do GitHub com a pasta lifeos do pacote, aguarde o deploy e atualize o aplicativo. Nenhuma alteração no Notion ou variável da Vercel é necessária.

Teste de hábitos e compilação de produção verificados. Este pacote inclui as funcionalidades e correções anteriores.
